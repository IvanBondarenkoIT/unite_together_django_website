# Структура проекту Unite Together

## 📂 Загальна структура

```
unite_together_django_website/
├── about_us/              # Додаток "Про нас"
├── accounts/              # Управління користувачами
├── coordination/          # Координація допомоги
├── donate/                # Система пожертв
├── homepage/              # Головна сторінка
├── persons/               # Управління особами
├── web_pages/             # Новости, проєкти, події
├── templates/             # HTML шаблони
├── static/                # Статичні файли (CSS, JS)
├── media/                 # Завантажені файли
├── staticfiles/           # Зібрані статичні файли
└── unite_together_django_website/  # Налаштування проекту
```

## 📦 Django Apps

### `about_us/`
**Призначення:** Інформація про організацію

**Основні моделі:**
- `Program` - програми організації
- `Document` - документи
- `Partners` - партнери
- `Contacts` - контактна інформація

**Основні views:**
- `about_us()` - головна сторінка "Про нас"
- `documents()` - документи
- `partners()` - партнери
- `contacts()` - контакти

### `accounts/`
**Призначення:** Аутентифікація та управління користувачами

**Основні моделі:**
- `Account` - розширена модель користувача

**Особливості:**
- Інтеграція з Django Allauth
- Соціальна аутентифікація (Google OAuth2)
- Кастомний pipeline для обробки соціальних логінів

### `web_pages/`
**Призначення:** Контент сайту - новини, проєкти, події

**Основні моделі:**
- `News` - новини з фото-галереями та зовнішніми посиланнями
- `Projects` - проєкти з категоріями
- `Events` - події
- `NewsGallery` - галерея фото для новин
- `ProjectGallery` - галерея фото для проєктів

**Основні views:**
- `news()` - список новин
- `news_detail()` - деталі новини
- `projects()` - список проєктів
- `projects_detail()` - деталі проєкту

**Template tags:**
- `news_tags.py` - теги для перекладу місяців

### `persons/`
**Призначення:** Управління особами, які потребують допомоги

**Основні моделі:**
- `Person` - основна модель особи
- `DocumentType` - типи документів
- `City` - міста

**Особливості:**
- Складні форми з валідацією
- Мультимовна підтримка
- Експорт даних (Excel)

### `homepage/`
**Призначення:** Головна сторінка сайту

**Основні моделі:**
- `Section` - секції головної сторінки
- `CallToAction` - призиви до дії

**Особливості:**
- Карусель новин
- Секції з контентом
- Адаптивний дизайн

### `donate/`
**Призначення:** Система пожертв через PayPal

**Особливості:**
- Інтеграція з PayPal IPN
- Обробка платежів
- Сторінки успіху/помилки

## 🎨 Frontend структура

### `templates/`
Шаблони організовані за додатками та типами:

```
templates/
├── base.html              # Базовий шаблон
├── aboutus/               # Шаблони "Про нас"
│   ├── aboutus-index.html
│   ├── about-us-documents.html
│   └── ...
├── news/                  # Шаблони новин
│   ├── desktop/           # Desktop версії
│   └── mobile/            # Mobile версії
├── projects/              # Шаблони проєктів
├── accounts/               # Шаблони аутентифікації
├── persons/               # Шаблони управління особами
└── includes/              # Часткові шаблони
    ├── new/
    │   ├── navbar.html    # Навігаційне меню
    │   └── ...
    └── ...
```

### `static/`
Статичні файли організовані за типами:

```
static/
├── css/
│   ├── news/              # Стилі для новин
│   ├── projects/          # Стилі для проєктів
│   ├── accounts/          # Стилі для акаунтів
│   └── ...
├── js/                    # JavaScript файли
└── img/                   # Зображення
```

**Важливо:** Файли з `static/` автоматично збираються в `staticfiles/` командою `collectstatic`.

## 🔧 Налаштування

### `unite_together_django_website/settings.py`
Головний файл налаштувань Django:

- **База даних:** Підтримка SQLite (dev) та PostgreSQL (prod)
- **Статичні файли:** WhiteNoise для продакшн
- **Медіа файли:** Локальне зберігання або Azure Blob Storage
- **Аутентифікація:** Django Allauth з Google OAuth2
- **Мови:** Українська (uk) та Англійська (en)

### Змінні оточення (`.env`)
Всі секрети та конфігурація зберігаються в `.env`:

- `SECRET_KEY` - секретний ключ Django
- `DEBUG` - режим відлагодження
- `RDS_*` - налаштування PostgreSQL
- `EMAIL_*` - налаштування email
- `PAYPAL_*` - налаштування PayPal
- `SOCIAL_AUTH_*` - налаштування OAuth2

## 🚀 Розгортання

### Локальна розробка:
1. Використовується SQLite
2. `DEBUG=True`
3. Статичні файли з `static/`

### Продакшн:
1. PostgreSQL на AWS/Azure
2. `DEBUG=False`
3. Статичні файли з `staticfiles/` через WhiteNoise
4. Медіа файли на Azure Blob Storage (опціонально)

## 📝 Best Practices

1. **Безпека:**
   - Всі секрети в `.env`
   - `.env` в `.gitignore`
   - Використання `python-decouple`

2. **Код:**
   - Закоментований код видалено
   - Чистий код без мертвого коду

3. **Структура:**
   - Логічна організація по додатках
   - Розділення desktop/mobile шаблонів
   - Модульні CSS файли

4. **Версіонування:**
   - Git для контролю версій
   - Змістовні коміти
   - Ветка `local-development` для розробки

## 🔍 Корисні команди

```bash
# Створити міграцію
python manage.py makemigrations <app_name>

# Застосувати міграції
python manage.py migrate

# Зібрати статичні файли
python manage.py collectstatic

# Створити суперкористувача
python manage.py createsuperuser

# Запустити сервер
python manage.py runserver
```
